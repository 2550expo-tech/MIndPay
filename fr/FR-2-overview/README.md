# FR-2 Overview Dashboard · ภาพรวม

**ผู้รับผิดชอบ:** พัชระพรชัย ค้าไป (GitHub-IOhmmy)

## FR นี้แก้ปัญหาอะไร

ผู้ใช้งานส่วนใหญ่ดูแค่ยอดเงินในแอปธนาคาร เห็นตัวเลขลดลงแต่ตอบไม่ได้ว่า เดือนนี้ใช้ไป
กับอะไรมากที่สุด หรือ สัปดาห์นี้ใช้มากกว่าปกติไหม ถ้าไม่สรุปให้เห็นภาพ
ผู้ใช้ก็ต้องไล่ดูทีละรายการเอง

## Requirement และเกณฑ์ผ่าน (Acceptance criteria)

**Requirement FR-2**
"แสดงรายรับ รายจ่าย ยอดคงเหลือ และยอดตามหมวด"

**Acceptance criteria**

1.ยอดคงเหลือ = ยอดตังต้น + รายรับ − รายจ่าย ที่ยืนยันแล้ว (แบบร่างไม่นับ)

2.เลือกช่วง วันนี้ / 7 วัน / 1 เดือน / 6 เดือน / 1 ปี และได้ยอดแยกหมวดหมู่

3.กราฟ 7 วันแสดงวันทีไม่มีรายจ่ายเปน 0

4.ปฏิทินการใช้จ่ายในแท็บรายการ: ไล่สีทองตามยอดใช้เทียบวันปกติของเดือน, จุดเขียว = มีเงินเข้า, แตะวันเพื่อดูเฉพาะวันนั้น, เลื่อนดูเดือนก่อนได้

5.จัดวันตามเวลาไทย ไม่ใช่ UTC 

6.สรุปเดือนแบบเรืองเล่า: ยอด หมวดที่ใช้มาก วันที่ใช้มาก นิสัย การจด และเทียบเดือนก่อนแบบจํานวนวันเท่ากัน

7.ยอดเงินรวมรายการที่เก่ากว่า 400 วันด้วย · สลับบัญชีไม่ค้างข้อมูลบัญชีเก่า · รีเฟรชไม่ทํารายการที่เพิ่งบันทึกหาย

8.เที่ยงคืนเวลาไทย "วันนี้" เริ่มใหม่เอง
