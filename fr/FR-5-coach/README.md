# FR-5 AI Coach · โค้ชน้องกล้า

**ผู้รับผิดชอบ:** Aoengthai Saesae (nullaxis9) **ชุดงาน:** ชุดที่ 4

## FR นี้แก้ปัญหาอะไร

ตัวเลขในแอปการเงินบอกว่า "เกิดอะไรขึ้น" แต่ไม่ได้บอกว่า "แล้วควรทำยังไง" ผู้ใช้หลายคนเห็นกราฟแล้วไม่รู้ว่าดีหรือแย่ หรือรู้สึกถูกตำหนิจนเลิกเปิดแอป FR-5 ให้น้องกล้า มาสคอตต้นกล้าสีทองของ MindPay เป็นโค้ชส่วนตัวที่อธิบายเฉพาะข้อมูลที่ผู้ใช้ยืนยันแล้ว ด้วยน้ำเสียงสุขุม เป็นมิตร และไม่ตำหนิ เช่น "สัปดาห์นี้หมวดอาหารสูงกว่าปกติ 40% ถ้าเป็นช่วงที่ต้องใช้จริงก็ไม่เป็นไร กล้าแค่อยากให้รู้ไว้นะ" น้องกล้าพูดออกเสียงภาษาไทยพร้อมซับไตเติล ปากขยับตามพยางค์ และตอบคำถามอิสระได้ เช่น "ซื้อรองเท้า 1,290 ได้ไหม" โดยบอกจำนวนวันที่เงินพอใช้ก่อนและหลังซื้อ แล้วให้ผู้ใช้เป็นคนตัดสินใจเอง

## Requirement และเกณฑ์ผ่าน (Acceptance criteria)

Requirement: "อธิบายข้อมูลที่ยืนยันแล้วให้เข้าใจง่าย" (29 ก.ย. เปลี่ยนจากโค้ช 3 โทนเป็นน้องกล้าที่พูดได้ ตามที่ผู้ใช้ขอ)

1. โค้ชคือน้องกล้า น้ำเสียงเดียว สุขุม เป็นมิตร เรียกตัวเองว่า "กล้า" ไม่ตำหนิ หน้าโค้ชและหน้าตั้งค่าไม่มีตัวเลือก 3 โทนแล้ว (TC-32, TC-50, E2E)
2. หาหมวดที่ 7 วันนี้สูงกว่าสัปดาห์ปกติ (เฉลี่ย 3 สัปดาห์ก่อนหน้า) ตั้งแต่ 25% และเพิ่มอย่างน้อย ฿100 (TC-31)
3. ยังไม่มีรายการที่ยืนยัน → ไม่วิจารณ์ แต่ชวนให้เริ่มจดรายการแรก (TC-32)
4. ใช้เกินงบเดือน บอกตรง ๆ ว่าเกินเท่าไร พร้อมปลอบว่า "ไม่ต้องโทษตัวเองนะ" (TC-34)
5. พูดออกเสียงภาษาไทยทีละท่อนพร้อมซับไตเติล อ่าน "฿1,290" เป็น "1290 บาท" และ "%" เป็น "เปอร์เซ็นต์" ปิดเสียงได้ เครื่องที่ไม่มีเสียงไทยยังแสดงซับไตเติลตามเวลาอ่าน และไม่ crash (TC-76, E2E)
6. น้องกล้าตัวใหญ่บนเวที หายใจ กะพริบตา ตอนพูดปากขยับ แตะแล้วกระโดดและเล่าเคล็ดลับไม่ซ้ำติดกัน และเปลี่ยนชุดบนเวทีได้เลย (TC-58, E2E)
7. ถามว่า "ซื้อ X ได้ไหม" แอปดึงราคาจากคำถามเอง เช่น "หูฟัง 1990 คุ้มไหม" = ฿1,990 แต่ "อีก 30 วัน" หรือ "2 ชิ้น" ไม่นับเป็นราคา แล้วส่งจำนวนวันก่อน/หลังซื้อไปให้ AI ตอบ (TC-89)
8. AI ได้รับเฉพาะยอดรวมตามหมวด ไม่มีรูปสลิป ชื่อคน หรือเลขบัญชี ห้ามแต่งตัวเลข ตอบไม่เกิน 90 คำเป็นประโยคพูด ไม่มีสัญลักษณ์รายการ (helper tests, MT-08)
9. จำกัดถามได้ 60 ครั้งต่อวันต่อคน นับแบบ atomic ส่งพร้อมกันหลายครั้งก็ไม่หลุดโควตา และข้อความผิดพลาดแสดงบนจอแต่ไม่อ่านออกเสียง (E2E key หาย, AI ไม่ว่าง, โหมดทดลอง)

## ทำงานยังไง

ข้อมูลที่ยืนยันแล้ว → ข้อเท็จจริง → คำพูดน้องกล้า → เสียงและซับไตเติล ผ่านไฟล์ดังนี้

1. **เปิดหน้าโค้ช** ที่ coach.tsx น้องกล้าทักทายด้วยเสียง (ธีมฮาโลวีนทักว่า "บู้! ตกใจไหม")
2. **หาข้อเท็จจริงในเครื่อง** ที่ insights.ts ฟังก์ชัน `buildInsights` ทำตามลำดับความสำคัญ

   2.1 ยังไม่มีรายการ → ชวนให้เริ่มจด แล้วหยุด

   2.2 Runway ต่ำกว่าเส้นสำรอง / critical / watch → บอกจำนวนวันและชวนไปลองปรับในหน้าเงินพอถึง (FR-6)

   2.3 `findCategoryIncrease` หาหมวดที่สูงกว่าปกติ ≥ 25% และ ≥ ฿100

   2.4 มีงบเดือน → เทียบยอดที่ใช้กับเวลาที่ผ่านไปของเดือน

   2.5 ไม่มีอะไรน่าห่วง → ชมว่าใช้เงินสม่ำเสมอ

3. **แตะการ์ด "สิ่งที่ควรรู้ตอนนี้"** แล้วน้องกล้าเล่าให้ฟัง ส่วนนี้ไม่ใช้ AI จึงใช้ได้แม้ออฟไลน์หรือโควตาหมด
4. **ถามคำถามอิสระ** coach.tsx เรียก `buildCoachContext` สรุปยอดรวมตามหมวด 7 และ 30 วัน ยอดคงเหลือ และ Runway ถ้ามีราคาในคำถาม `priceInQuestion` (price.ts) ดึงราคาออกมา แล้ว `runwayAfterPurchase` (FR-6) คำนวณจำนวนวันหลังซื้อแนบไปด้วย
5. **ส่งไปเซิร์ฟเวอร์** ที่ services/coach.ts → Edge Function coach ตรวจว่าเข้าสู่ระบบแล้ว ตัดโควตาด้วย `take_ai_quota` แล้วส่งให้ AI พร้อมกฎของน้องกล้า
6. **พูดคำตอบ** ที่ useKlaTalk.ts `talkChunks` ตัดคำตอบเป็นท่อนสั้น `speakable` แปลงให้อ่านถูก แล้ว tts.ts / tts.web.ts พูดทีละท่อน KlaStage ขยับปากตามพยางค์ ถ้าไม่มีเสียงไทย ซับไตเติลจะอยู่ตามเวลาอ่านจาก `talkMs`

กฎทั้งหมดเป็นฟังก์ชันล้วนใน `src/domain` ที่ทดสอบได้โดยไม่ต้องเรียก AI และ API key ของ AI อยู่บนเซิร์ฟเวอร์เท่านั้น แอปไม่ส่งชื่อร้าน ชื่อคน หรือรูปสลิปไปให้ AI

## ข้อจำกัดและงานต่อไป

- **ผู้ใช้ใหม่ได้คำเตือนหมวดเพิ่มขึ้นทั้งที่ใช้เท่าเดิม (เตือนผิด):** ใช้ค่าอาหารวันละ ฿100 ทุกวันมา 14 วัน ได้ข้อความ "หมวดอาหารสูงกว่าปกติ 200%" เพราะ "สัปดาห์ปกติ" หารด้วย 3 สัปดาห์เสมอ แม้มีข้อมูลแค่ 1 สัปดาห์ (ใช้ครบ 28 วันแล้วไม่เตือน) → งานต่อ: หารด้วยจำนวนสัปดาห์ที่มีข้อมูลจริง แบบเดียวกับที่ FR-6 ทำกับค่าเฉลี่ยรายวัน
- **ราคาที่พิมพ์เป็นคำไทยไม่ถูกดึงออกมา (ไม่มีตัวเลขก่อน/หลังซื้อ):** "รองเท้าพันสองร้อยเก้าสิบ ซื้อได้ไหม" ได้ราคาว่าง ส่วน "ไปเที่ยว 3 วัน งบ 2500 พอไหม" ก็ไม่ถูกนับเพราะไม่มีคำว่าซื้อหรือจ่าย → งานต่อ: ใช้ `thaiNumberWords` ของ FR-3 แปลงเลขคำไทย และเพิ่มคำว่า "งบ" เป็นคำถามเรื่องใช้เงิน
- **ซับไตเติลอาจตัดระหว่างตัวเลขกับหน่วย (เสียงเว้นจังหวะแปลก):** "...จากปกติราว 920" กับ "บาท ถ้าเป็นช่วง..." ถูกแยกเป็นคนละท่อน → งานต่อ: ห้ามตัดท่อนระหว่างตัวเลขกับคำว่า "บาท"
- **การห้ามแต่งตัวเลขเป็นแค่คำสั่งใน prompt (AI อาจพูดตัวเลขผิด):** เซิร์ฟเวอร์ไม่ได้ตรวจว่าตัวเลขในคำตอบมีอยู่ในข้อมูลจริง → งานต่อ: ตรวจตัวเลขทุกตัวในคำตอบกับข้อมูลที่ส่งไป ถ้าไม่ตรงให้ตอบใหม่หรือแจ้งผู้ใช้
- **AI เห็นแค่ยอดรวมตามหมวด (ตอบบางคำถามไม่ได้):** "เดือนนี้จ่ายร้านไหนบ่อยสุด" ตอบไม่ได้ เพราะไม่ได้ส่งชื่อร้านไปเพื่อความเป็นส่วนตัว → งานต่อ: ให้ผู้ใช้เลือกเปิดการส่งชื่อร้านเองได้
- **เสียงขึ้นกับเสียงไทยในเครื่อง และยังไม่ได้ลองบนมือถือจริง:** เครื่องที่ไม่มีเสียงไทยจะมีแค่ซับไตเติล ส่วนเสียงน้องกล้าและธีมฮาโลวีนยังไม่ได้ทดสอบบนมือถือจริง → งานต่อ: ทำ MT-08 บน Android และ iPhone
